# Refactor Baseline (Phase 1)

Дата фиксации baseline: 2026-04-25.

## Цели baseline

- Зафиксировать рабочие сценарии перед SOLID-рефакторингом.
- Проверять регрессии после каждого PR.
- Иметь одинаковые команды локальной и CI-проверки.

## Обязательные команды проверки

```bash
./mvnw test
./mvnw -Pquality verify
```

Примечание: локально требуется `JAVA_HOME` на JDK 21.

## Критичные пользовательские сценарии (smoke checklist)

1. Старт приложения и отображение главного меню.
2. Создание персонажа и переход в HUD.
3. Сохранение и повторная загрузка персонажа.
4. Редактирование персонажа и сохранение изменений.
5. Удаление персонажа из экрана выбора.
6. Экспорт описания персонажа в `.txt`.
7. Импорт/экспорт персонажа на экране transfer.
8. Смена языка RU/EN.
9. Открытие заметок персонажа и сохранение текста.
10. Базовая проверка апдейта (без падения UI).

## Технический baseline (на дату фиксации)

- Main code: ~9.2k строк Java.
- Tests: 4 тестовых файла (~255 строк).
- Основные hotspots для декомпозиции:
  - `overview/ui/TopBar.java`
  - `screen/StartScreen.java`
  - `theme/factory/AppButtonFactory.java`
  - `repository/JsonCharacterRepository.java`

## Правила для следующих PR

1. Каждый PR обязан проходить `test` и `quality`.
2. Каждый архитектурный шаг должен сохранять smoke-сценарии.
3. Любые изменения в flow создания/сохранения персонажа требуют обновления smoke checklist.
